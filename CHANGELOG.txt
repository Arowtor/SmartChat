SmartChat 0.5.0 Beta 1 - Public Beta Release (based on development line 0.7.41)
- Added a Settings control for the maximum number of locally stored chat lines (1-10000; default 1000).
- Clarified that the age limit and stored-line limit are separate from the number of lines replayed at login.
- Updated the privacy documentation for opt-in local Chat History and Player Journal behavior.
- Added a limited end-user permission to download, install and run the unmodified AddOn while keeping modification and redistribution rights reserved.
- Elevated the optional Network Map from a restrained node diagram to a richer animated relationship constellation, while keeping it inside the existing Social Hub window.
- Added layered connection wires (soft colored glow, bright main stroke and a lighter core) so relationship paths read clearly against the dark canvas.
- Added capped traveling energy pulses along selected connections, animated accent halos and node sparkles, plus an ambient starfield with staggered shimmer.
- Improved Midnight and Neon themes with deeper backgrounds, brighter cyan/violet accents and a subtle grid; Minimal remains available as the quieter alternative.
- Expanded node entrance fades to a slower staggered reveal. The Animation control now governs the visual motion package rather than only the entry fade.
- Reduce Motion suppresses looping shimmer, traveling pulses and entrance transitions while leaving the map and its controls fully usable.
- Preserved the strict opt-in design: Network Map remains OFF by default. Before the user presses Enable Network Map, no canvas, node/edge pools, ambient decorations or map animation groups are created. The first snapshot and effects are built only after explicit activation or a manual refresh while enabled.
- Disable stops node, halo, sparkle and connection-pulse animations, hides the canvas and clears rendered pools. Navigating away stops effects; returning to the Network page rebuilds the current on-demand snapshot and restarts effects only if enabled.
- Preserved all source contact and Player Journal data. No new tracker, polling loop, network request or idle OnUpdate loop was added; OnUpdate remains limited to an active user drag-pan.
- Syntax-checked all Lua files and ran static checks for default-off/lazy creation, animation gating, cleanup and bounded pools. Not tested inside the live WoW: Forever client; actual texture availability, animation playback, frame cost and layout need in-game verification.

SmartChat 0.7.40 - Optional Social Hub Network Map
- Added a Network category inside the existing Social Hub window. It does not create a second window or replace List, Friends, Guild, My Groups, Player Profiles or the main chat.
- Network Map is opt-in and OFF by default. Before explicit activation, the page shows only its enable/description controls; the graph canvas, contact-node pool and connection-line pool are not created.
- On activation or manual Refresh, builds a bounded snapshot from existing Friends, Guild, current Group, Battle.net, Whisper, Favorites, My Groups and locally recorded Group Journal data. It adds no new event tracking, polling, timers or network requests.
- Added three layouts (Node Graph, Radial and Mind Map), three themes (Midnight, Neon and Minimal), 80/100/120 percent zoom, drag-to-pan, vertical and Shift+wheel horizontal scrolling, relationship filters and a maximum visible-node control.
- Added curved connector polylines, colored relationship hubs, contact status dots, relationship badges, Class/Level metadata, tooltips, selected-node highlighting, profile/Whisper actions and optional one-time staggered node entrance fades. Reduce Motion suppresses entrance effects; there are no looping animations.
- Disabling the map stops active animations, hides the canvas and clears rendered node/edge content. All Friends, Guild, Whisper, My Groups, Player Journal and other source data remain untouched.
- The map does not infer mutual Friends, hidden Battle.net characters, exact group-time overlap or Dungeon completion. Unknown data remains unknown; recorded partners depend on Journal history captured while tracking was enabled.
- Added the optional Network Map request and implementation status to PROJECT_ROADMAP.txt. Preserved all previous chat, sound, shortcut, font, link, Social Hub and Journal features.
- Syntax-checked all Lua files and ran static/source checks for default-off behavior, lazy canvas creation, bounded node counts, layout controls and disable cleanup. Not tested inside the live WoW: Forever client.

- No new polling loops, permanent timers, external network requests, or Journal event tracking were added.
- Syntax and mocked-data tests cover template create/copy/update/delete, selected-contact snapshots, backup preview/export/import round trips, duplicate handling, offline/account-only filtering, already-grouped detection and five-player Party capacity.
